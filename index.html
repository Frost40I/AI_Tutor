About Me

저는 일상속 다양한 문제를 관찰하는 것에 흥미를 느끼는 개발자입니다. 친구가 없는 저는 ChatGPT을 접하며 AI가 이를 완벽히 대체할 수는 없어도 빈 부분을 매우는 것이 가능하다 생각하게 되었고 그러한 존재가 될 수 있는 AI에 대해 많은 관심을 가져 왔고 많은 대화형 인공지능, 페르소나 챗봇 사이트를 접해왔습니다.

이번 AI 튜터 프로젝트는 친구가 없거나 다른사람과 있는 것이 불편한 사람들에게 다른 사람들과 비슷한 경험을 주기 위해 기획되었습니다. 이 프로젝트로 혼자하는 공부와 모두와 하는 공부 간의 격차를 줄이고자 합니다.

문제 정의

학생들이 학습을 할 때 때론 혼자 하는 것 보다는 친구들 여럿이 모여 하는 것이 더 효과적이기도 합니다. 하지만 모두에게 친구가 있는 것은 아니고 설령 친구가 있더라도 성격적 이유로 모여서 하는 공부가 더 불편하다 여기는 사람도 있습니다. 저는 혼자서도 공부할 때 친구와 함께 공부한다는 느낌을 주고, 같이 공부를 할 때의 효과를 볼 수 있게 하고자 하는 것이 목표였습니다. 하지만 기존 PDF 읽기 기반 챗봇은 상당히 딱딱한 말투를 기본으로 하고 있으며 질문을 하면 '답'을 내놓아 사용자의 학습에는 도움을 주지 않는다고 생각하게 되었습니다.

아키텍처 / 설계

핵심 전략으로 RAG(Retrieval-Augmented Generation) 아키텍처를 채택했습니다. 데이터 프라이버시와 비용 효율성을 위해 외부 API 대신 Ollama를 사용하여 로컬 LLM(exaone3.5:2.4b)을 구동했습니다. 백엔드는 Python FastAPI를 기반으로 비동기 API 서버를 구축했습니다. 사용자가 업로드한 PDF는 텍스트로 변환 및 분할(Chunking)되어 ChromaDB 벡터 저장소에 임베딩됩니다. 단순 Q&A를 넘어선 튜터링 기능을 위해, 대화 상태 관리(State Management) 로직을 tutor_service에 집중시켜 사용자의 상태(예: ANSWERED_WRONG, HINT_REQUESTED)를 추론하고 반응을 동적으로 결정하도록 설계했습니다.

아키텍처 다이어그램

핵심 기능

동적 튜터링 엔진 및 대화 상태 관리

사용자의 모든 대화 기록(Chat History)을 프론트엔드에서 받아, 백엔드의 '상태 관리자'가 현재 대화의 **'상태'**를 실시간으로 분석했습니다. ANSWERED_WRONG 상태에서는 '채점' 대신 '소크라테스식 역질문'을 생성하도록, ANSWERED_CORRECT 상태에서는 '칭찬 및 요약'과 '다음 학습 제안'을 하도록 동적 프롬프트 빌더(Prompt Builder)를 구현했습니다. 이를 통해 LLM이 고정된 응답이 아닌, 튜터의 페르소나(예: 친근한 선배)와 현재 학습 맥락에 맞는 지능적인 대화(역질문, 힌트 제공, 채점, 격려)를 수행하도록 했습니다.

핵심 기능 1 스크린샷
대화 맥락을 인지하는 RAG 파이프라인

사용자의 "왜?" 또는 "그럼 그건 뭐야?" 같은 짧은 후속 질문을 처리하기 위해 '검색어 재구성(Query Rewriting)' 로직을 도입했습니다. Vector DB를 검색하기 전, LLM이 전체 대화 맥락을 바탕으로 모호한 질문을 "([이전 주제]가 왜 중요한가?)"와 같이 구체적인 검색어로 변환하도록 했습니다. 이렇게 재구성된 검색어를 ChromaDB에 질의함으로써, 대화의 맥락에 정확히 부합하는 PDF 원문(컨텍스트)을 검색(Retrieve)하여 LLM에 제공, 응답의 정확성과 관련성을 극대화했습니다.

결과 및 성과

  • 정적인 PDF 문서를 상호작용이 가능한 지능형 학습 교재로 성공적으로 변환.
  • 사용자의 오답 시 즉각적인 정답 제시가 아닌, '역질문'과 '단계별 힌트'를 제공하여 사용자의 능동적인 사고를 유도하는 튜터링 시스템 구축.
  • 모든 LLM 추론과 데이터 처리를 로컬(Ollama, ChromaDB)에서 수행하여, 완전한 데이터 프라이버시를 보장하는 AI 애플리케이션을 구현함.

회고 (Lessons Learned)

  • LLM을 활용한 지능형 봇 설계 시, 대화 상태 관리와 동적 프롬프트 엔지니어링이 튜터의 페르소나와 지능을 결정하는 가장 중요한 요소임을 깊이 이해했습니다.
